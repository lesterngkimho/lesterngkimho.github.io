# lesterngkimho.github.io

Personal and professional website, built with Jekyll and hosted on GitHub Pages at [www.lesterngkimho.my](https://www.lesterngkimho.my).

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000. Restart the server after changing `_config.yml`.

## Where to edit

- **Site settings, social links, résumé link:** `_config.yml`
- **Projects:** `_data/projects.yml` (one entry per project)
- **Pages:** `index.markdown`, `about.markdown`, `hire-me.markdown`, `contact.markdown`, `projects.markdown`
- **Blog posts:** `_posts/`
